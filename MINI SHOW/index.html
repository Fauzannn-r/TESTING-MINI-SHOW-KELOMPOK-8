Simulasi. Praktik. Paham. Bersama NetFix

Media pembelajaran interaktif berbasis web untuk melatih logika diagnosis gangguan jaringan komputer pada mata pelajaran Administrasi Infrastruktur Jaringan (AIJ) Siswa Kelas XI SMK TKJ tanpa risiko merusak perangkat laboratorium fisik.

Panduan Operasional Singkat

  1. Pilih level skenario gangguan pada menu Pilih Kasus (Mudah, Sedang, Sulit).
  2. Amati indikator topologi jaringan pada Simulation Dashboard.
  3. Ikuti siklus keputusan Amati → Duga → Uji → Simpulkan → Evaluasi.
  4. Gunakan instrumen pengujian (LAN Tester, ipconfig, ping, nslookup) untuk menemukan akar masalah.
